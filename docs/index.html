Setup in 3 Minutes

1

Download & Extract

Click the download button above. Extract the ZIP anywhere on your computer.

2

Install Python Dependencies

Open the extracted folder and double-click install.bat. This installs Flask and Playwright.

3

Launch the App

Double-click run_web_app.bat. The dashboard opens at http://localhost:5000. Login to Naukri and start applying!

⚠️ Important: This is a Desktop Tool

This app runs on YOUR computer and controls YOUR Chrome browser. It cannot be hosted as a website because it needs to interact with your browser directly. Each person downloads and runs it on their own laptop.
