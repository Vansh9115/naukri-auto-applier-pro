Quick Setup Guide for Friends

1

Make Sure Python is Installed

Ensure Python 3.10+ is installed on your PC from python.org.
IMPORTANT: During installation, check the box that says "Add python.exe to PATH"!

2

Download & Extract

Click the Download ZIP button above. Right-click the downloaded `.zip` file and click Extract All.

3

Run Setup (`install.bat`)

Open the extracted folder and double-click install.bat. This automatically installs Flask and Playwright.
(If Windows Defender pops up "Windows protected your PC", click "More info" -> "Run anyway").

4

Start App (`run_web_app.bat`)

Double-click run_web_app.bat. The app opens in your browser at http://localhost:5000!

💡 Troubleshooting Guide for First-Time Users

  • If double-clicking `install.bat` flashes and closes immediately: Python is missing! Download Python from python.org and check "Add python.exe to PATH" during installation.
  • If Windows shows "Windows protected your PC": Click "More info" on the blue screen, then click "Run anyway".
  • Is Google Chrome required? Yes! Google Chrome must be installed on your laptop.
